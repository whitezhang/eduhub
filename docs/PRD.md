## 1. 产品定义

EduHub 是一个 **网站**（浏览器访问），信奥训练与模拟评测 OJ。用户在网页里看题、写代码、提交；服务端负责账号、题库、竞赛和评测。

路径按官方：**GESP → CSP-J/S → NOIP → NOI**。本产品只做训练和模拟，不承办 CCF 官方报名与发证。官方赛一律外链 [GESP](https://gesp.ccf.org.cn/)、[NOI](https://www.noi.cn/)。

交互对标 [力扣题库](https://leetcode.cn/problemset/) 的筛选与列表，题型和赛制按 OI（完整程序、测试点部分分），不是力扣函数题。

---

## 2. 范围

**做**

1. 学生：看题、在网页作答（输入即保存为结果）、编程题可运行样例、看测试点分数。
2. 教练/管理员：开模拟赛、布置题单、管题目。
3. 四个一级入口：首页、题库、竞赛、外部竞赛。
4. **进度公开**：未登录也可查看全部学生进度。
5. **同一套网站适配手机浏览器**（不做独立 App）。

**不做**

- 家长账号、家长端、监护人绑定。
- 官方报名、收费、证书。
- 讨论区、题解社区、求职、图形化 IDE。
- 桌面客户端、独立手机 App、机房锁屏、selfEval、交互题、提交答案题。

## 4. 信息架构

```text
网站（登录与否都可见）：首页 | 题库 | 竞赛 | 外部竞赛 | 进度
教练登录后另有：题目/比赛管理
```

### 首页（公开，无需登录）

三块内容，不做每日一题、不做「继续上次」：

1. **学习信息学的好处**：能力、升学与竞赛路径价值（文案由后台维护）。
2. **教学大纲**：按 GESP → CSP-J/S → NOIP → NOI 列出各阶段知识点与对应题单入口。
3. **学习的时间节点**：学年时间轴（如 GESP 一年四次、CSP 两轮、NOIP、NOI），标明建议准备窗口。

### 题库

左侧：GESP / CSP-J / CSP-S / NOIP / NOI、题单。  
中部表：状态、题号、标题、来源、分数、难度、通过率。  
筛选：赛事、组别、语言（C++/Python）、状态。  
做题页：题面在上、作答在下；无提交按钮，输入即保存。

### 适配（手机浏览器）

一套页面，响应式布局，不单独做 m 站或 App。

- 导航：宽屏顶栏；窄屏收成菜单按钮。
- 首页、进度、外部竞赛：手机上必须可读（家长常用手机看进度）。
- 题库表格：窄屏改为卡片或只保留关键列（状态、标题、分数）。
- 做题/竞赛写代码：手机可用，但不针对触控键盘做专门 IDE。
- 教练后台：允许手机看，复杂录入仍以电脑为准。

### 竞赛（本平台）

创建 / 报名 / 进入考场。赛制只保留三种：

- 练习：即时返回测试点
- OI：赛中无正式反馈，最后一次提交计分，赛后出分
- IOI：赛中返回得分，取最高分

支持编程题比赛；GESP/CSP 第一轮需要时，同一场可加客观题（选择/判断）。

### 外部竞赛

只读赛历 + 官网链接 + 跳转到已上架真题。不在本平台代报名。

### 进度（公开，无需登录）

任何人打开即可看到全部学生：题库完成情况、通过/部分分、比赛成绩。可点进某人看做题状态（不展示源代码）。登录不是查看进度的前提。

## 5. 功能清单（即本期全部）

| 模块 | 功能 |
| --- | --- |
| 首页 | 好处说明、教学大纲、学习时间节点（公开，手机可读） |
| 题库 | 列表、筛选、搜索、题面、题单（窄屏卡片/精简列） |
| 做题 | 上题面下作答、输入即保存、运行样例、测试点矩阵 |
| 题型 | 传统编程题（含部分分/子任务/可选 SPJ）；客观题 |
| 竞赛 | 练习 / OI / IOI；倒计时；赛后成绩与榜单 |
| 外部竞赛 | 赛历、外链、真题入口 |
| 进度 | 公开全员看板，无需登录 |
| 教练 | 布置题单、创建比赛、题目管理 |
| 后台 | 题目上下架、赛历、账号、首页文案（好处/大纲/时间节点） |

语言：C++、Python。编译与运行全部在服务端评测机完成，浏览器不装编译器。

---

## 6. 评测（必要规则）

- 传统题：时限、内存、stdin/stdout 或指定文件名；样例可见，测试点不可见。
- 结果：CE / TLE / MLE / RE / WA / AC + **得分**。练习显示测试点；OI 赛中只显示「已提交」。
- 「运行样例」只用公开样例，不等于正式分，界面写明。

---

## 7. 架构

```text
浏览器 ──► Nginx 静态 + /api 反代 ──► 本机一个 Node 进程（SQLite + 串行评测）
```

前端：一套 SPA，桌面与手机浏览器共用。  
服务端：单机单进程；提交排队串行评测。部署对齐 blog（Nginx + systemd，不用 Docker）。  
进度、首页无需鉴权；作答写入账号与管理需登录。未登录作答只存在本机。

## 8. 合规（最短）

- 文案标明非 CCF 官方。
- 真题仅上架有授权的内容。
- 进度对所有访客公开；提交源代码仍仅本人与教练可见。不做家长登录。
