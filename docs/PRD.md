# EduHub 产品总纲

| 项 | 内容 |
| --- | --- |
| 产品名 | EduHub |
| 版本 | v1.9 |
| 日期 | 2026-08-24 |
| 原则 | 只做必要功能；家长无账号；进度公开；非 CCF 官方 |

---

## 1. 这是什么

EduHub 是一个**信奥训练网站**。学生在浏览器里看题、写代码、提交；服务端管账号、题库、比赛和评测。

路径按官方：**GESP → CSP-J/S → NOIP → NOI**。本站只做训练和模拟，不代报名、不发证。官方赛一律外链 [GESP](https://gesp.ccf.org.cn/)、[NOI](https://www.noi.cn/)。

交互参考力扣的筛选与列表；题型和赛制按 OI（完整程序、测试点部分分），不是力扣函数题。

---

## 2. 范围

| 做 | 不做 |
| --- | --- |
| 学生刷题、整卷练习、运行样例、看测试点分数 | 家长账号、家长端 |
| 教练开模拟赛、布置题单、管题目 | 官方报名、收费、证书 |
| 公开首页、新闻、榜单 | 讨论区、题解社区、图形化 IDE |
| 同一套网站适配手机浏览器 | 桌面客户端、独立 App |
| 未登录可看全员进度 | selfEval、交互题、提交答案题 |

---

## 3. 角色

| 角色 | 能做什么 |
| --- | --- |
| 访客 | 看首页、新闻、榜单 |
| 学生 | 刷题、参赛；自己的代码仅自己可见 |
| 教练 / 管理员 | 管题目、比赛、账号、首页文案 |

家长不注册，直接打开榜单即可看所有人进度。

---

## 4. 信息架构

```text
公开：首页 | 新闻（政策 / 公开赛）| 教学大纲 | 题库 | 外部资料 | 榜单 |
登录后：上述页面看真实数据；教练另有 /studio 管理
```

| 入口 | 路径 | 登录 |
| --- | --- | --- |
| 首页 | `/` | 否 |
| 新闻 | `/news`（默认 `/news/policy`） | 否 |
| 教学大纲 | `/syllabus` | 是（未登录模糊预览） | `PRD-教学大纲.md` |
| 题库 | `/problems` | 是 |
| 外部资料 | `/external` | 是 |
| 榜单 | `/progress` | 是 |
| 管理 | `/studio` | 教练 |

详情见各子 PRD：`PRD-首页.md`、`PRD-新闻.md`、`PRD-教学大纲.md`、`PRD-登录门禁与模糊预览.md`。

---

## 5. 核心功能

| 模块 | 说明 |
| --- | --- |
| 首页 | STAR 叙事：为何学、学什么、怎么练、得什么 |
| 新闻 | 国家政策出处、一线公开赛链接（可点击核验） |
| 题库 | 题单 → 试卷列表 → 整卷竖排作答，输入即保存 |
| 做题 | 上题面下作答；运行样例；测试点矩阵 |
| 题型 | 传统编程题（部分分/子任务）；客观题 |
| 竞赛 | 管理端发卷；学生从题库进入整卷练习 |
| 外部资料 | 赛历、官网外链、真题入口 |
| 榜单 | 全员进度看板（无源码） |
| 教练 | 布置题单、创建比赛、网页改题 |

语言：C++、Python。编译与评测全在服务端，浏览器不装编译器。

---

## 6. 评测规则

- 传统题：时限、内存、stdin/stdout；样例可见，测试点不可见。
- 结果：CE / TLE / MLE / RE / WA / AC + 得分。练习显示测试点；OI 赛中只显示「已提交」。
- 「运行样例」只用公开样例，不等于正式分，界面须写明。

---

## 7. 技术概要

```text
浏览器 → Nginx（静态 + /api 反代）→ 本机单 Node 进程（SQLite + 串行评测）
```

一套 Vue SPA，桌面与手机共用。部署：Nginx + systemd，不用 Docker。详见 `架构设计.md`。

---

## 8. 合规

- 文案标明非 CCF 官方。
- 真题仅上架有授权内容。
- 进度对访客公开；提交源码仅本人与教练可见。
