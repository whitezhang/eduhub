## 2. GESP 客观题

### 两源各有长短

| 来源 | 问题 | 可靠部分 |
| --- | --- | --- |
| CCF 试题 PDF | 题面/选项可能错序、页码碎片 | 卷面完整；**节首答案表**；编程题 |
| CCF 解析 PDF | 排版噪声 | 逐题解析正文 |
| AdaCpp | 无编程题；部分套卷缺失 | 题面/选项干净；答案覆盖率高 |

**结论**：按字段互补，不是一方覆盖另一方。

### 题号格式

```text
GESP-{ym}-{CPP|PY}{level}-{C|J}{seq:02d}
例：GESP-202512-CPP6-J03
```

套卷对齐键：`(ym, lang, level)`。

### PDF 客观题答案在哪

答案在每一类题目的**章节标题正下方**（不在卷末）：

```text
1 单选题（每题 2 分，共 30 分）
┌──────┬───┬───┬ … ─┐
│ 题号 │ 1 │ 2 │     │
│ 答案 │ C │ C │ …   │
└──────┴───┴───┴ … ─┘
第 1 题 …
```

判断题答案可能是矢量图形（非文字），需本机视觉识别（见下）。

### 字段合并规则

写入 `seed/gesp-merged/`（进 git，导入读此目录）。

| 字段 | 优先 | 回退 |
| --- | --- | --- |
| 题面/选项 | AdaCpp（有卷时） | PDF 试题（过质量检测） |
| 答案 | PDF 试题节首表 | 解析 PDF → AdaCpp |
| 解析 | CCF 解析 PDF | AdaCpp |
| 编程题 | 仅 PDF 试题 | AdaCpp 不参与 |

**PDF 题面质量检测**（未过检不用作题面）：

- 含页眉页脚碎片
- 连续孤立行号列
- 选项区异常（某选项过长或 A–D 不全）

**答案冲突**：采用 PDF 试题节首表，并在 `review_note` 记冲突。

### 判断题视觉识别（仅本机）

判断题 √/× 常为 PDF 矢量图：

```bash
pip install -r src/op/requirements-gesp-vision.txt
python src/op/gesp_import.py --skip-crawl --reparse --no-import
```

可用 OpenAI 视觉或本地 Ollama（`gesp_tf_vision.py`）。未配置时用矢量路径启发式。线上 deploy 不装此依赖。

### 流水线

```text
1. 试题 PDF  → seed/gesp/           （题面 + 节首答案表 + 编程）
2. 解析 PDF  → 并入 seed/gesp/      （逐题解析）
3. AdaCpp    → seed/gesp-adacpp/
4. 合并       → seed/gesp-merged/
5. 导入 DB   → gesp_objective_import.py（客观）+ gesp_import.py --prog-only（编程）
```

线上 `deploy-server.sh` 均 `--skip-crawl`，只用 seed。

## 5. 常用命令

**GESP 客观题**

```bash
python src/op/gesp_import.py                    # 试题 PDF
node src/op/scrape-adacpp-gesp.mjs              # AdaCpp
python src/op/gesp_adacpp_import.py             # 合并入 DB（过渡期）
```

**GESP 编程**

```bash
python src/op/gesp_import.py --prog-only
python src/op/gesp_import.py --skip-crawl --reparse --no-import
```

**同步 seed 到服务器**（不传 PDF）：`src/op/sync-gesp.sh` 或 `sync-gesp.ps1`

## 7. 「有答案」判定

指**能否自动判分**，不是题面是否完整。

| 题型 | 算有答案 | 字段 | 来源 |
| --- | --- | --- | --- |
| 选择/判断 | 标准选项非空 | `choice_json.answer` | 合并后 PDF 节首表 > AdaCpp |
| 编程 | 参考程序非空 | `solution_code` | CCF 试题 PDF |

**不算有答案**：只有样例/测例、没有参考程序。

**产品行为**：无答案题可见可作答，不自动评分；教练端标「无答案」。Studio 可补全。

实现见 `api.mjs` 中 `hasAnswerSql()` / `problemHasAnswer()`。
