# 数据库设计

| 项 | 内容 |
| --- | --- |
| 引擎 | SQLite |
| 文件 | `src/rd/server/data/runtime/{test\|prod}/eduhub.db` |
| 代码 | `src/rd/server/db.mjs` → `schema()` / `migrate()` |
| 关联 | `架构设计.md` |

测试与生产各用一份库，路径由 `EDUHUB_ENV` 区分。表结构两边相同。

---

## 1. 表清单

按用途分组，共 **17 张表**。

| 分组 | 表 | 一句话 |
| --- | --- | --- |
| 账号 | `users`、`sessions` | 谁在用、登录态 |
| 站点文案 | `cms_blocks` | 首页/大纲等可编辑文案（键值对） |
| 题库 | `problems`、`testcases`、`problem_lists`、`problem_list_items` | 题目、测例、题单分类 |
| 整卷练习 | `contests`、`contest_problems`、`contest_registrations` | 试卷、卷内题目、报名记录 |
| 做题进度 | `submissions`、`paper_drafts`、`paper_cursors` | 提交与得分、草稿、做到哪一题 |
| 新闻 | `policy_items`、`contest_items` | 政策链接、公开赛链接（新闻页用） |
| 其它 | `external_events`、`guest_usage` | 外部资料日历、访客限速计数 |

**不在库里的数据**：测例文件在 `runtime/{env}/problems/{题目id}/`；种子 JSON 在 `data/seed/`；题目正式 JSON 在 `data/catalog/problems/`。

---

## 2. 字段说明

约定：`1/0` 表示布尔；时间为 ISO 字符串或 SQLite `datetime('now')`；带 `JSON` 的字段存 JSON 字符串。

### users — 用户

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| username | TEXT | 登录名，唯一 |
| password_hash | TEXT | 密码哈希 |
| password_plain | TEXT | 明文密码（仅学生账号 Studio 展示用；教练恒为空） |
| display_name | TEXT | 显示名 |
| role | TEXT | `student` 学生 / `coach` 教练 |
| grade | TEXT | 年级（可选） |
| language | TEXT | 默认语言偏好（可选） |
| created_at | TEXT | 创建时间 |

### sessions — 登录会话

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| sid | TEXT | 会话 ID（Cookie） |
| user_id | INTEGER | 对应用户 |
| expires_at | INTEGER | 过期时间（Unix 毫秒） |

### cms_blocks — 站点文案块

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| key | TEXT | 块名，主键 |
| body | TEXT | 内容：纯文本或 JSON 字符串 |

常用 `key`（见 §3）。

### problems — 题目

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| code | TEXT | 题号，唯一（如 `GESP-202309-PY-1-03`） |
| title | TEXT | 标题 |
| source | TEXT | 来源标识，与题单 `problem_lists.source` 对应（如 `gesp`、`csp-j`） |
| difficulty | TEXT | 难度标签 |
| time_ms | INTEGER | 时间限制（毫秒） |
| memory_mb | INTEGER | 内存限制（MB） |
| io_mode | TEXT | 输入输出方式，默认 `stdin` |
| languages | TEXT | 可提交语言 JSON 数组，如 `["cpp","python"]` |
| type | TEXT | `traditional` 编程题 / `choice` 选择判断题 |
| statement | TEXT | 题面（Markdown/HTML） |
| sample_in | TEXT | 样例输入 |
| sample_out | TEXT | 样例输出 |
| sample_note | TEXT | 样例说明 |
| choice_json | TEXT | 选择题结构 JSON（选项、答案等） |
| full_score | INTEGER | 满分，默认 100 |
| published | INTEGER | 是否对学生可见：`1` 可见 / `0` 隐藏 |
| review_note | TEXT | 教练备注（审核用） |
| solution_code | TEXT | 标程/参考答案（编程题） |

### testcases — 测例（元数据）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| problem_id | INTEGER | 所属题目 |
| seq | INTEGER | 序号 |
| score | INTEGER | 该测例分值 |
| is_sample | INTEGER | 是否样例：`1` 是 |
| input_rel | TEXT | 输入文件相对路径 |
| output_rel | TEXT | 输出文件相对路径 |

实际文件在 `runtime/{env}/problems/{problem_id}/` 下。

### problem_lists — 题单分类（题库侧栏）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| slug | TEXT | URL 用短名，唯一 |
| title | TEXT | 展示名（如「GESP 1–8 级」） |
| source | TEXT | 筛试卷用，对应 `problems.source` |
| blurb | TEXT | 一句说明 |

### problem_list_items — 题单与题目关联

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| list_id | INTEGER | 题单 |
| problem_id | INTEGER | 题目 |
| seq | INTEGER | 排序 |

主键 `(list_id, problem_id)`。

### contests — 试卷（题库里的「一套卷」）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| title | TEXT | 试卷名 |
| rule | TEXT | 赛制：`practice` 练习 / `oi` / `ioi` |
| duration_min | INTEGER | 时长（分钟） |
| start_at | TEXT | 开始时间 |
| end_at | TEXT | 结束时间 |
| published | INTEGER | 是否发布 |
| is_demo | INTEGER | 是否演示卷 |

### contest_problems — 试卷题目

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contest_id | INTEGER | 试卷 |
| problem_id | INTEGER | 题目 |
| seq | INTEGER | 卷内题序 |

主键 `(contest_id, problem_id)`。

### contest_registrations — 试卷报名

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contest_id | INTEGER | 试卷 |
| user_id | INTEGER | 用户 |

主键 `(contest_id, user_id)`。OI 赛制提交前写入。

### submissions — 提交记录

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | INTEGER | 主键 |
| user_id | INTEGER | 提交人 |
| problem_id | INTEGER | 题目 |
| contest_id | INTEGER | 所属试卷（可选，单题练习为空） |
| language | TEXT | `cpp` / `python` / `choice` |
| mode | TEXT | `full` 全测 / `sample` 样例 |
| code | TEXT | 提交内容 |
| status | TEXT | 见 §4 |
| score | INTEGER | 得分 |
| result_json | TEXT | 评测详情 JSON |
| created_at | TEXT | 提交时间 |
| judged_at | TEXT | 评测完成时间 |

### paper_drafts — 整卷草稿

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| user_id | INTEGER | 用户 |
| contest_id | INTEGER | 试卷 |
| problem_id | INTEGER | 题目 |
| language | TEXT | 语言 |

主键 `(user_id, contest_id, problem_id)`。

### paper_cursors — 整卷做到哪题

| --- | --- | --- |

| contest_id | INTEGER | 试卷 |

| updated_at | TEXT | 更新时间 |

主键 `(user_id, contest_id)`。

### policy_items — 政策（新闻页）

| 字段 | 类型 | 含义 |
| --- | --- | --- |

### contest_items — 公开赛资讯（新闻页）

| --- | --- | --- |

| key | body 形态 | 用途 |
| --- | --- | --- |

## 4. 枚举与约定

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| users.role | `student`, `coach` | |
| problems.type | `traditional`, `choice` | |
| contests.rule | `practice`, `oi`, `ioi` | |
| policy_items.status / contest_items.status | `published`, `pending`, `rejected` | 新闻只展示 `published` |
| submissions.mode | `full`, `sample` | |
| submissions.status | `queued`, `judging`, `AC`, `PART`, `WA`, `CE`, `submitted` 等 | 评测流水态 + 结果态 |
| published / is_sample / is_demo | `0`, `1` | |

**两张「contest」别混**：`contests` 是站内练习卷；`contest_items` 是新闻里的公开赛链接。

**有答案判定**：`choice` 看 `choice_json.answer`；`traditional` 看 `solution_code` 是否非空。
