# 登录门禁与模糊预览 PRD

| 项 | 内容 |
| --- | --- |
| 版本 | v0.3 |
| 日期 | 2026-08-24 |
| 状态 | 已实现 |
| 关联 | `PRD.md` |
| 原则 | 访客能感知「进了哪一页」，但看不到真实数据；登录后无感恢复 |

---

## 1. 解决什么问题

旧做法：访客点大纲/题库等受保护入口时，**直接跳回首页**并弹登录框。顶栏仍高亮「首页」，和访客心智不符。

**目标**：访客点受保护入口时，URL 和顶栏高亮对准目标页，主区显示**模糊骨架预览**，登录框叠在最上层；登录成功后加载真实数据。

---

## 2. 范围

| 做 | 不做 |
| --- | --- |
| 顶栏高亮与 URL 一致 | 用假数据截图做模糊层 |
| 主区模糊 + 骨架占位 | 独立注册、找回密码 |
| 自动弹登录框 | 全站强制登录（首页仍公开） |
| 登录后去模糊、拉真实数据 | |
| 覆盖 `/syllabus`、`/problems`、`/external`、`/progress` | |

---

## 3. 用户故事

1. **访客点题库**：地址栏 `/problems`，顶栏「题库」高亮；列表区模糊骨架；登录框自动弹出。关掉登录框仍停留在模糊态（受保护页上点遮罩**不能**关登录框）。
2. **访客从受保护页回到公开页**（首页、新闻等）：登录框**自动关闭**；页面正常可读，无模糊。
3. **访客登录成功**：弹层关闭，数据正常加载，模糊消失。
4. **已登录用户**：无模糊、无额外弹层。
5. **访客在首页点「登录」**：只弹登录框，URL 仍为 `/`，主区不模糊；若再点顶栏「新闻」等公开页，登录框关闭。

---

## 4. 交互规则

### 状态

```text
访客 + 公开页（/、/news）     → 正常内容；loginOpen 应为 false
访客 + 受保护页              → authWall：顶栏目标高亮 + 主区模糊 + loginOpen
已登录 + 任意页              → 正常
```

**离开受保护页**：路由进入 `requiresAuth !== true` 的页面时，若仍未登录，**自动 `closeLogin()`**。

### 模糊层

| 元素 | 处理 |
| --- | --- |
| `<main>` 内页面 | `blur(6px)` + 降透明度 + 禁止点击 |
| 顶栏、登录弹层 | 不模糊 |
| 页脚 | 随主区模糊 |

**占位内容**：骨架屏（灰块 + 标题条），**禁止请求真实 API**。不用真实数据渲染后再模糊。

### 登录弹层

- 标题「登录」；副文案按当前页面（如「登录后查看题库」）。
- **受保护页**：点遮罩不关闭（保持模糊预览 + 引导登录）。
- **公开页**：不显示登录框（除非访客刚点顶栏「登录」且未跳转）。
- 登录成功：关闭弹层 → 各页 `load()` → 清除模糊。

---

## 5. 技术要点

### 路由

```text
未登录 + requiresAuth：
  session.openLogin(to.fullPath)
  return true   // 允许进入目标路由

未登录 + 公开页：
  session.closeLogin()
  return true
```

### 会话状态

| 字段 | 含义 |
| --- | --- |
| `loginOpen` | 登录弹层是否显示 |
| `loginReturnTo` | 登录成功后跳转路径 |
| `authWall` | 主区是否处于模糊预览 |

可用 getter `showAuthWall = requiresAuth && !user`。

### 受保护页面

```text
onMounted:  if (!user) return   // 不请求 API
            await load()

watch(user): if (user) await load()
```

模板：`AuthWallSkeleton`（未登录）/ 真实内容（已登录）。

### 安全

- 前端不拉受保护 API；后端仍 401（双重保险）。
- 模糊层**不替代**后端鉴权；JS Challenge 仍作用于匿名公开接口。

## 7. 验收

1. 未登录点「题库」：URL `/problems`，顶栏高亮，模糊骨架，自动弹登录。
2. 受保护页上关登录框：仍停留模糊态（遮罩不可关）。
3. 未登录从「教学大纲」切回「首页」或「新闻」：登录框消失，内容正常显示。
4. 登录成功：模糊消失，数据正常，不闪回首页。
5. 已登录：无模糊、无自动弹登录。
6. 首页点「登录」：只弹层，主区不模糊；再进「新闻」则弹层关闭。
7. Network：模糊态下无受保护 API 200 响应。

---

## 8. 无障碍

- 登录弹层：`role="dialog"`、`aria-modal="true"`。
- 模糊主区：`aria-hidden="true"`。
- `prefers-reduced-motion`：减弱或关闭 blur，仅保留遮罩。
