# EduHub UI 设计

| 项 | 内容 |
| --- | --- |
| 依据 | `PRD.md` v1.9 |
| 版本 | v1.5 |
| 日期 | 2026-08-24 |
| 风格 | 简约学术：讲义 / 试卷，不是力扣深色竞赛风 |
| 范围 | 全站一套壳；桌面 + 手机浏览器 |

---

## 1. 设计目标

站点给中小学生、教练、未登录家长看。首页是大纲和好处，进度公开。

- **要**：打开像一份印刷讲义；入口一眼能找到；做题页像拆开试卷（上题面下作答，输入即保存）。
- **不要**：插画运营页、暗色主题、大 Banner、游戏化徽章、emoji。
- **否决**：Element Plus 默认亮蓝、大圆角卡片阴影、渐变 Hero、Inter/Roboto。

技术上可用 Element Plus 表格和表单，但颜色、圆角、字体必须吃本文 token。

---

## 2. 视觉语言

### 灵感

信奥现场材料：CCF 试卷（宋体题面、等宽样例框）、学校通知、教学大纲的「一、二、三」。签名元素是**章节号 + 细横线**，不是大色块 Hero。

### 颜色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F2F1EC` | 页底 |
| `--surface` | `#FFFEFA` | 内容区、表、编辑器外框 |
| `--ink` | `#1C1B17` | 标题、主按钮、正文 |
| `--muted` | `#6B6860` | 说明、次要信息 |
| `--rule` | `#D4D0C6` | 顶栏底线、表线、章节线 |
| `--indigo` | `#2F4A6A` | 链接、当前导航、题号 |
| `--ok` | `#2F5D3A` | 满分 / AC |
| `--mid` | `#8A5A12` | 部分分 |
| `--bad` | `#8B2E2A` | CE / 未通过 |
| `--code-bg` | `#EBE8E0` | 样例、行内代码 |

主按钮：`--ink` 底、白字、圆角 2px。次按钮：透明 + `--rule` 描边。状态不只靠颜色：满分写「100」、未做写「—」。

### 字体

| 角色 | 字体 | 用法 |
| --- | --- | --- |
| 标题 | Noto Serif SC | 站名、首页 h1、章节名 |
| 正文 | Noto Sans SC | 导航、段落、表、表单 |
| 等宽 | IBM Plex Mono | 题号、代码、测试点 |

正文行高 1.7。表和按钮用黑体，不要全站衬线。

### 尺度

- 阅读栏宽：首页 40rem；题库/进度 72rem；做题页通栏。
- 页边：桌面 32px，手机 16px。
- 圆角：控件 2px。无投影，分割只用 1px `--rule`。
- 动效：仅按钮 `:active` 和链接下划线。尊重 `prefers-reduced-motion`。

## 3. 全站壳

```text
+--------------------------------------------------+
|  站名    首页 新闻 教学大纲 题库 外部资料 榜单  登录  |
|  ------------------------------------------------|
|                   主内容                           |
|  ------------------------------------------------|
|  非 CCF 官方 · 仅供训练                            |
+--------------------------------------------------+
```

**顶栏**：左站名链 `/`；中间导航链；当前项 `--indigo` + 底边 1px。窄屏收成汉堡菜单。

**页脚**：一行非官方声明，小字 `--muted`。

**登录**：顶栏点「登录」出居中小面板。无公开注册；账号由教练添加。

## 4. 各页要点

### 首页 `/`

纵向三章（STAR），不要卡片宫格。章号衬线小字「一、二、三」+ `--rule` 横线。S1/S2 段末链到新闻页，不在首页列长表。详见 `PRD-首页.md`。

### 新闻 `/news`

页内二级标签「政策 / 公开赛」。单栏 `.read` 布局。详见 `PRD-新闻.md`。

首页正文须精简、大白话（字数上限见 `PRD-首页.md` §1），勿在首页堆政策/赛事长文。

### 题库 `/problems`

三层：题单 → 试卷列表 → 整卷竖排作答。

- 左栏题单；手机改横滑 chips。
- 右侧只列**试卷**，点「进入」→ `/problems/papers/:id`。
- 整卷页：全部题目同一页纵向排列，左侧题号目录，输入即保存。
- 单题路由 `/problems/:id` 保留（管理预览）。

### 做题页

上题面、下作答，不要左右分栏。

- **试卷条**：换题、看进度（带 `contest` 参数时显示）。
- **题面区**：题干、样例、测试点分值。Markdown 渲染（`marked` + `highlight.js`）。
- **作答区**：选项或编辑器。输入约 1 秒自动保存。
- **没有「提交」「保存进度」**。编程题可有「运行样例」（非正式分）。
- 无标准答案：「本题还没有标准答案。作答会记下，但不评分。」

### 外部资料 `/external`

学年时间轴 + 官网链接。按钮写「前往 NOI 官网」，不写「立即报名」。

### 榜单 `/progress`

家长未登录也可看（登录后看真实数据）。桌面表；手机每人一块。点名字进详情，**无代码**。不要奖杯排行榜。

### 管理 `/studio`

同一顶栏，二级：题目、首页文案、比赛、账号。不要深色 Admin 皮肤。

- **题目**：试卷表 + 单题表；编辑页保存写 SQLite + `catalog/problems/{题号}.json`。
- **首页文案**：STAR 各字段。
- 学生题库只显示有标准答案的已发布题。

## 5. 组件约定

| 组件 | 做法 |
| --- | --- |
| 筛选 | 文字 + 下划线，不要实心 chip |
| 标签 | 小字 + `--code-bg`，圆角 2px |
| 测试点矩阵 | 等宽表：点号、结果、分 |
| 空态 | 一句人话，不要插画 |
| 加载 | 表区写「载入中」 |
| 排队 | 「前方还有 N 份评测」 |

按钮文案：「运行样例」「上一题」「下一题」「开始做题」「继续做题」「进入」。不要「提交」「Submit」。

---

## 6. 响应式

断点：`<768px` 窄，`≥768px` 宽。触控热区 ≥ 44px。

| 页 | 窄屏 |
| --- | --- |
| 壳 | 汉堡菜单 |
| 首页 | 三章单列 |
| 题库 | chips + 卡片 |
| 做题 | 上题面下作答 |
| 榜单 | 卡片 |
| 管理 | 能看列表；改题面以电脑为准 |

---

## 7. 无障碍

- 正文与纸色对比 ≥ 4.5:1。
- 链接带下划线，不只靠颜色。
- 键盘焦点可见 2px `--ink` 框。
- 非官方声明在页脚。

---

## 8. 实现备忘

- 全局 CSS 变量写一处；Element Plus 颜色吃 token。
- 题面：`marked` + `highlight.js`。Monaco 只用于作答编辑器。
- 站名、导航、页脚抽 `AppShell`。
- 登录门禁模糊态见 `PRD-登录门禁与模糊预览.md`。

---

## 9. 验收

- 首页三章、无 Banner、政策链到新闻页。
- 做题页上题面下作答；无提交按钮；输入即保存。
- 主色不是 Element 默认蓝；无大阴影圆角卡片。
- 页脚有非官方说明。
- 未登录受保护区显示模糊骨架。
